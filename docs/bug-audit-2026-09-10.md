# Audit bug Hararest — 10 September 2026

Audit mencakup kode, routing, konfigurasi, serta pengujian 13 modul aplikasi.
Temuan di bawah diperbaiki di workspace. Ini bukan jaminan tidak ada bug lain:
tes otomatis menggunakan fixture/mocks, sedangkan probe internet hanya memeriksa
keterjangkauan beberapa layanan dan kemampuan runtime lokal.

Validasi publik berlaku pada koneksi langsung Pinterest/Xiaohongshu dan probe ukuran
media. Perlindungan ini tidak mengendalikan koneksi yang dibuat oleh executable

atau port nonstandar ditolak. Request halaman publik memakai koneksi langsung agar
validasi DNS pada socket tidak dilewati melalui proxy lingkungan.

## Konfigurasi dan build

- Kebutuhan Node diperbarui menjadi 22.12+ sesuai dependency Puppeteer yang terpasang.
- `package-lock.json` tidak lagi diabaikan Git; Docker dan petunjuk instalasi memakai `npm ci`.
- Docker menggunakan `PUPPETEER_SKIP_DOWNLOAD=true` dan memasang dependency group `yt-dlp[default]` untuk EJS.
- Binding default Compose menjadi `127.0.0.1`; alamat Tailscale tetap dapat dikonfigurasi melalui `.env`.
- Build produksi mengecualikan tes. `npm run typecheck` memeriksa aplikasi dan tes secara terpisah.
- Konfigurasi ts-jest mengikuti `isolatedModules`; tes tidak lagi membutuhkan `forceExit` atau transport log berkas.
- README menjelaskan FFmpeg, Tesseract beserta bahasa `ind+eng`, format body OCR, dan batas parameter.

## Riset internet yang mendasari perubahan

- Meta mengumumkan perpindahan Threads ke `threads.com`; middleware harus menerima domain tersebut. [Pengumuman Meta](https://about.fb.com/news/2025/04/new-features-threads-web-experience/).
- yt-dlp menyediakan `--no-playlist` dan `--print after_move:filepath` untuk mengendalikan unduhan dan mengambil path sesudah postprocessing. [Dokumentasi yt-dlp](https://github.com/yt-dlp/yt-dlp#output-template).
- Node perlu diaktifkan dengan `--js-runtimes node`; instalasi pip dapat memakai `yt-dlp[default]` untuk memperoleh skrip EJS yang sesuai. [Panduan EJS resmi](https://github.com/yt-dlp/yt-dlp/wiki/EJS).
- Axios mendokumentasikan timeout dan perilaku `maxRedirects: 0`; dukungan short link perlu mengelola redirect secara eksplisit. [Konfigurasi Axios](https://axios-http.com/docs/req_config).
- Brave membatasi `count` hingga 20. [Dokumentasi Brave Search](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started).
- Waifu.im mendokumentasikan `/images` dengan `IncludedTags` dan `IsNsfw`; ejaan parameter diselaraskan. [Dokumentasi Waifu.im](https://docs.waifu.im/docs/getting-started/).
- Node mendokumentasikan error subprocess, stream stdin, dan penghentian proses melalui timeout. [Dokumentasi child_process](https://nodejs.org/api/child_process.html).
- ts-jest menjelaskan kebutuhan `isolatedModules` untuk mode modul hybrid. [Dokumentasi ts-jest](https://kulshekhar.github.io/ts-jest/docs/guides/esm-support).

## Hasil verifikasi dan batasan

Baseline: 8 suite / 22 tes lulus, tanpa cakupan langsung Brave, OCR, Pinterest,
Pixiv, dan NSFW. Sesudah perbaikan: **15 suite / 109 tes lulus**, termasuk tes
regresi dan validasi route tambahan. Typecheck, lint, serta build dijalankan.
`npm ci --dry-run --ignore-scripts --no-audit --no-fund` lulus. Smoke test
server hasil build menghasilkan 200 untuk `/health` dan `/`, serta 404 untuk route
tidak dikenal. Syntax kedua script Python diperiksa dengan parser Python. Chrome headless lokal
berhasil membuka halaman fixture; binary lokal yt-dlp melaporkan versi `2026.07.04`.

Probe HTTP anonim pada saat audit (hasil dapat berbeda dengan scraper Python/browser):

| Target | Hasil |
| --- | --- |
| Threadster, SaveTwitter, Pinterest, Xiaohongshu | Landing page HTTP 200 |
| Waifu.im `/tags`, dokumentasi Purrbot | HTTP 200 |
| SnapInsta, FDown, Tikwm, Pixiv | HTTP 403 |
| NHentai API dan Danbooru `/status.json` | Koneksi gagal dari mesin audit |

HTTP 200 landing page tidak membuktikan unduhan media berhasil; HTTP 403 dari probe
fetch juga tidak membuktikan semua fallback akan gagal. Login, cookie, tantangan
anti-bot, perubahan HTML upstream, dan ketersediaan posting tetap perlu diverifikasi
dengan URL media yang dapat diakses pada lingkungan deployment.

Tesseract dan Docker tidak terpasang pada mesin audit, sehingga OCR nyata dan build
container belum dijalankan. Brave diuji memakai key fixture, tanpa panggilan berbayar.
Probe metadata YouTube awal dengan video uji `BaW_jenozKc` mengembalikan video tidak
tersedia; ini bukan hasil pengujian unduhan audio/video yang berhasil.

Probe lanjutan dengan `--js-runtimes node` pada video publik `jNQXAC9IVRw` berhasil
mengembalikan ID dengan exit code 0. yt-dlp masih melaporkan fallback dari embedded
initial data ke API. Keberhasilan ini memverifikasi ekstraksi metadata tanpa cookie,
bukan pengunduhan serta konversi audio/video penuh.
